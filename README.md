# MyTodoList 

MyTodoList is a simple console-based To-Do List application developed using Java. It allows users to manage their daily tasks through a menu-driven interface.

This is my first Java project, built to practise Java fundamentals and problem-solving.

# Features

- **Add Task:** Add new tasks to your list.
- **View Tasks:** Display all tasks with their completion status.
- **Update Task:** Modify existing task names.
- **Delete Task:** Remove tasks from the list.
- **Mark as Completed:** Update a task's status to completed.
- **Input Validation:** Handle empty task names and invalid menu inputs.
- **Duplicate Prevention:** Prevent adding an existing task.

# Technologies Used

- Java
- ArrayList
- Iterator
- Scanner
- Loops and Conditional Statements

# Requirements

- Java JDK installed
- IntelliJ IDEA or any Java IDE
- Git (optional)

# How to Run

1. Clone this repository:

   
   git clone https://github.com/VanneSiddartha/MyTodoList.git
   

2. Open the project folder in your IDE.

3. Compile the Java file:

   
   javac src/Main1.java
   

4. Run the application:

   
   java -cp src Main1


##  Menu Options

```text
===== MyTodoList =====

1. Add Task
2. View Task
3. Update Task
4. Delete Task
5. Mark Task as Completed
6. Exit
```

##  Note

Tasks are stored temporarily in memory using ArrayLists. They will be lost when the application is closed.

Persistent storage will be considered for a future version.
